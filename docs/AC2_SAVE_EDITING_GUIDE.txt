SECTION 1: FILE STRUCTURE
================================================================================

All AC2 save files (OPTIONS and .SAV) use the same header format:

Offset      Size    Description
------      ----    -----------
0x0-0x3     4       File size (excluding 8-byte header, little-endian)
0x4-0x7     4       CRC32 checksum (little-endian)
0x8+        varies  Actual file data

IMPORTANT: When calculating checksum, use data starting at offset 0x8 only.
The first 8 bytes are NOT included in the checksum calculation.

SECTION 3: EDITING WORKFLOW
================================================================================

STEP 1: DECRYPT SAVE (if encrypted)
    - Use PFDTool or Bruteforce Save Data to decrypt PARAM.PFD
    - Files will be marked in ~files_decrypted_by_pfdtool.txt

STEP 2: BACKUP ORIGINAL FILE
    - Always keep an untouched copy

STEP 3: EXTRACT DATA FOR CHECKSUM
    - Remove first 8 bytes (header)
    - Keep only data from offset 0x8 onwards

STEP 4: HEX EDIT
    - Make changes at desired offsets (see Section 4/5)
    - Note: Offsets in this guide are relative to file start (include header)

STEP 5: RECALCULATE CHECKSUM
    - Use appropriate CRC32 parameters for file type
    - Calculate on data WITHOUT the 8-byte header

STEP 6: REBUILD FILE
    - Recalculate file size (data length, excluding header)
    - Write new 4-byte size at offset 0x0
    - Write new 4-byte checksum at offset 0x4
    - Append edited data

STEP 7: RE-ENCRYPT/RE-SIGN (if needed)
    - Use PFDTool or Bruteforce Save Data to update PARAM.PFD

SECTION 4: OPTIONS FILE OFFSET MAP

SYSTEM/META
-----------
0x4-0x7         Checksum
0x7C-0x7D       Game/Patch Version

-----------------
0x1F3           Subtitles toggle (00=off, 01=on)
0x21E           Spoken language selector
0x222-0x225     Spoken language ID:
                - B597CC50 = English

                - 7AFCF62B = Italian

SECTION 10: QUICK REFERENCE - COMMON TASKS
================================================================================

UNLOCK AUDITORE FAMILY CRYPT (Uplay):
1. Decrypt OPTIONS file
2. Change byte at 0x498 from 00 to 01
3. Recalculate CRC32 (poly=0x4C11DB7, init=0x0, xor=0x1BF3278A)
4. Update header with new checksum
5. Re-sign save

UNLOCK ALL UPLAY CONTENT:
Set these offsets to 01:
- 0x462 (Theme)
- 0x474 (Throwing Knives)
- 0x486 (Altair Outfit)
- 0x498 (Auditore Crypt)

UNLOCK ALL DLC MAPS:
Set these offsets to 01:
- 0x3D2, 0x3E4, 0x3F6 (Templar Lairs)
- 0x582 (Battle of Forli)
- 0x5A6 (Bonfire of Vanities)
